# Competitive Intelligence Agent 🤖

An AI agent that analyzes what real developers say about your competitors 
on Hacker News and GitHub — and turns it into a PM brief in 60 seconds.

## What It Does

Enter any competitor + your product. The agent:
- Pulls real developer discussions from Hacker News
- Searches GitHub issues for pain points and feature requests
- Claude synthesizes everything into an actionable PM brief

## Output Includes
- How users actually perceive the competitor
- Top 3 market gaps nobody is solving
- What you should build in the next 90 days
- Most underserved customer segment

## Built With
- n8n (workflow orchestration)
- Claude (Anthropic) — AI synthesis
- Hacker News Algolia API (free)
- GitHub Search API (free)
